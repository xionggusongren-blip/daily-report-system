1. フォルダ構成

システムは以下のような構成になっています：

C:\Tools\daily-report-system\ ├── app.js # メインアプリケーション ├── start.bat # サーバー起動バッチ ├── stop.bat # サーバー停止バッチ ├── start_service.bat # 自動起動用バッチ ├── db/ │ └── database.sqlite # データベースファイル ├── docs/ │ ├── manual.html # ユーザー向けマニュアル │ └── admin-guide.html# このファイル ├── views/ # 画面ファイル └── logs/ # ログファイル

2. サーバーの起動・停止

エクスプローラーから操作する場合

日報システムのフォルダを開き、バッチファイルをダブルクリックします。

ファイル 用途
start.bat サーバーを起動（コンソール画面が開く）
stop.bat サーバーを停止
start_service.bat バックグラウンドで起動（タスクスケジューラ用）

コマンドラインから操作する場合

# フォルダに移動 PS> cd C:\Tools\daily-report-system # サーバー停止 PS> .\stop.bat # サーバー起動 PS> .\start.bat
注意
start.bat で起動した場合、コンソール画面を閉じるとサーバーも停止します。 常時起動させる場合は、タスクスケジューラを使用してください。

3. システムの更新（Git操作）

基本的な更新手順

# 1. フォルダに移動 PS> cd C:\Tools\daily-report-system # 2. サーバーを停止 PS> .\stop.bat # 3. 最新の変更を取得 PS> git fetch origin # 4. 変更を適用（mainブランチの場合） PS> git pull origin main # 5. サーバーを起動 PS> .\start.bat

開発ブランチの変更を取り込む場合

# 開発ブランチの変更をマージ PS> git fetch origin PS> git merge origin/claude/fix-ranking-loading-CaFOs

よく使うGitコマンド

コマンド 説明
git status 現在の状態を確認
git log --oneline -5 最近のコミット履歴を表示
git fetch origin リモートの最新情報を取得
git pull origin main mainブランチの変更を取得・適用
git branch -a 全ブランチを表示

4. PowerShellでの操作

PowerShellの起動方法

  1. Windowsキー + R を押す
  2. powershell と入力してEnter

重要：現在のフォルダのファイルを実行する

PowerShellでは、現在のフォルダにあるファイルを実行する際に .\（ドット + バックスラッシュ）を付ける必要があります。

# 正しい書き方 PS> .\start.bat PS> .\stop.bat # 間違い（エラーになる） PS> start.bat # NG: .\がない PS> \start.bat # NG: ドットがない
コマンドプロンプト（cmd）の場合
コマンドプロンプトでは .\ は不要です。
start.bat とそのまま入力できます。

5. 自動起動の設定

Windowsの起動時にサーバーを自動起動させる設定です。

タスクスケジューラでの設定手順

  1. 「タスク スケジューラ」を開く（Windowsキー → 「タスク スケジューラ」で検索）
  2. 右側の「基本タスクの作成」をクリック
  3. 名前を入力（例：「日報システム自動起動」）
  4. トリガー：「コンピューターの起動時」を選択
  5. 操作：「プログラムの開始」を選択
  6. プログラム/スクリプト：C:\Tools\daily-report-system\start_service.bat
  7. 開始（オプション）：C:\Tools\daily-report-system
  8. 「完了」をクリック
ヒント
作成したタスクを右クリック → 「実行」で動作確認ができます。

6. バックアップ

重要なファイル

定期的にバックアップを取るべきファイル：

ファイル 内容
db/database.sqlite 全データ（日報、ユーザー、顧客情報など）

手動バックアップ

# サーバーを停止してからバックアップ PS> .\stop.bat PS> Copy-Item .\db\database.sqlite .\db\database_backup_$(Get-Date -Format "yyyyMMdd").sqlite PS> .\start.bat

7. トラブルシューティング

サーバーが起動しない

  • ポート3000が他のアプリで使用されていないか確認
  • Node.jsがインストールされているか確認（node --version）
  • logs/server.log でエラーを確認

stop.batが動作しない

  • PowerShellの場合は .\stop.bat と入力
  • 管理者権限で実行してみる

Gitでエラーが出る

  • git status で現在の状態を確認
  • ローカルの変更がある場合は git stash で一時退避してから pull

画面が更新されない

  • ブラウザのキャッシュをクリア（Ctrl + F5）
  • サーバーを再起動

データベースエラー

  • サーバーを停止
  • database.sqlite のバックアップを確認
  • 必要に応じてバックアップから復元
