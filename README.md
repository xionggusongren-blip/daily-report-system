# 営業日報システム セットアップガイド

## 動作要件
- Windows 10/11
- Node.js 18以上（https://nodejs.org/ からLTS版をインストール）

## インストール手順

### 1. ファイルの配置
ZIPファイルを展開し、任意のフォルダに配置してください。
例: `C:\Tools\daily-report-system\`

### 2. 初回起動
`start.bat` をダブルクリックして起動します。
初回は必要なパッケージが自動的にインストールされます（数分かかります）。

### 3. アクセス
ブラウザで以下のURLにアクセスしてください：
```
http://localhost:3000
```

### 4. 初期ログイン
以下のアカウントでログインできます：

| ユーザー名 | パスワード | 役割 |
|-----------|-----------|------|
| admin | admin123 | 管理者 |
| manager | manager123 | 上長 |
| user1 | user123 | 営業 |
| user2 | user123 | 営業 |

※ 本番運用前にパスワードを変更してください

## 他のPCからアクセスする場合

### ファイアウォールの設定
1. Windowsの設定 → プライバシーとセキュリティ → Windowsセキュリティ
2. ファイアウォールとネットワーク保護 → 詳細設定
3. 受信の規則 → 新しい規則
4. ポート → TCP → 特定のローカルポート: 3000
5. 接続を許可する → 適切なプロファイルを選択 → 名前を付けて完了

### アクセスURL
他のPCからは以下のURLでアクセスします：
```
http://[サーバーPCのIPアドレス]:3000
```

IPアドレスの確認方法：
```
ipconfig
```
→ IPv4アドレスを確認

## バックアップ

### 手動バックアップ
`backup.bat` をダブルクリックすると、`backups` フォルダにバックアップが作成されます。

### 自動バックアップの設定（推奨）
Windowsタスクスケジューラで毎日自動バックアップを設定できます。

1. タスクスケジューラを開く（taskschd.mscを実行）
2. 「タスクの作成」をクリック
3. 全般タブ：
   - 名前: 日報システムバックアップ
   - 「ユーザーがログオンしているかどうかにかかわらず実行する」を選択
4. トリガータブ：
   - 新規 → 毎日 → 開始時刻を設定（例: 23:00）
5. 操作タブ：
   - 新規 → プログラムの開始
   - プログラム: `C:\Tools\daily-report-system\auto_backup.bat`
   - 開始: `C:\Tools\daily-report-system`
6. OK → パスワードを入力して保存

### バックアップからの復元
1. サーバーを停止（Ctrl+C）
2. `backups` フォルダから復元したいファイルを選択
3. ファイル名を `database.sqlite` に変更してルートフォルダにコピー
4. サーバーを再起動

## トラブルシューティング

### 「Node.jsがインストールされていません」と表示される
→ https://nodejs.org/ からNode.js LTS版をインストールしてください

### ポート3000が使用中
→ 他のアプリケーションがポート3000を使用しています
→ 環境変数でポートを変更できます：
```bat
set PORT=8080
node app.js
```

### 他のPCからアクセスできない
→ ファイアウォールの設定を確認してください
→ 同じネットワーク内にいることを確認してください

## ファイル構成
```
daily-report-system/
├── start.bat          # 起動用バッチ（手動起動、ウィンドウ表示）
├── start_service.bat  # サービス起動用（タスクスケジューラ用、バックグラウンド）
├── stop.bat           # 停止用バッチ
├── backup.bat         # 手動バックアップ用
├── auto_backup.bat    # 自動バックアップ用
├── app.js             # メインアプリケーション
├── package.json       # 依存パッケージ定義
├── database.sqlite    # データベース（起動後に生成）
├── backups/           # バックアップ保存先
├── logs/              # ログ保存先（サービス起動時）
├── views/             # 画面テンプレート
├── public/            # 静的ファイル
└── db/                # DB初期化スクリプト
```

## 常時起動PCでの自動起動設定

### タスクスケジューラでPC起動時に自動起動

1. `Win + R` → `taskschd.msc` → Enter
2. 右側「タスクの作成」をクリック

**全般タブ:**
- 名前: `日報システム起動`
- 「ユーザーがログオンしているかどうかにかかわらず実行する」を選択
- 「最上位の特権で実行する」にチェック

**トリガータブ:**
- 「新規」→ 「スタートアップ時」を選択 → OK

**操作タブ:**
- 「新規」をクリック
- プログラム/スクリプト: `C:\Tools\daily-report-system\start_service.bat`
- 開始（オプション）: `C:\Tools\daily-report-system`
→ OK

3. パスワードを入力して保存

※ `start_service.bat` はバックグラウンドで起動し、ログは `logs` フォルダに出力されます

### サーバーの停止

`stop.bat` をダブルクリックするとサーバーが停止します。
